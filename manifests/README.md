# manifests

`sources.json` is generated by `uv run kev-fetch` in `benchmarks/baseline`.
Do not edit it by hand.

- `upstream`: the pinned kev git commit.
- `checkpoints`: facts read from each checkpoint's `head.pt` (base repository
  and revision, head_dim, temperature, LoRA rank, dtype). The base pins come
  from `head.pt`, not from the model cards.
- `sources`: every pinned file with its byte count and SHA-256. Adapter
  repositories and base repositories are pinned to explicit revisions. The
  fetcher downloads each file at its pinned revision, never an unpinned
  snapshot, and verifies size and SHA-256 before skipping an existing file.
- `converted`: artifacts produced by `uv run kev-convert-head`
  (`head.safetensors` + `head.meta.json` per checkpoint). Rust reads only
  these; it never parses `head.pt` (a PyTorch pickle).
- `python_environment`: the baseline package pins and the reason for them.

Weights live in `.cache/kev` (or `$KEV_RS_HOME`), never in git.
